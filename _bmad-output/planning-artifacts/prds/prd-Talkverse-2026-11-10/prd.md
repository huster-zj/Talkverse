# PRD: Talkverse MVP

## 0. 文档目的
这份 PRD 定义 Talkverse 的 MVP：一个网页语音产品，让用户和"像到爆表"的真实名人（首批马斯克、特朗普、乔布斯）对话。读者是未来的协作者和下游流程（UX / 架构 / 故事拆分）。词汇以 §3 术语表为准；推断处内联 `[ASSUMPTION: …]` 并在 §9 汇总。本文档建立在头脑风暴意图文档（`brainstorm-intent.md`）之上，只承载决策、不重复过程。

## 1. 愿景
Talkverse 是一个"对话的世界"：在网页上，用户开口和一个真实名人的**蒸馏版**对话——用他的语气、他的思路，针对用户此刻的处境，给出"换作他会怎么想"的判断。用户不是在读他的访谈、刷他的推特，而是在和他本人（的模拟版）说话。

MVP 只做一件事，并把这一件事做到爆表：**用语音，和一个像到爆表的名人对话。** 首批 3 人——马斯克（科技/创业）、特朗普（政治）、乔布斯（已故产品家）——既覆盖不同领域，也天然测试了"在世人物"与"历史人物"两类。

## 2. 目标用户

### 2.1 待办任务（JTBD）
- 让一个我仰慕的头脑（如马斯克），针对我此刻的具体处境，给出"他会怎么看"的判断——**随身智囊 / 思考外挂**。
- 低门槛日常形态：打个招呼、问一句"你最近在忙啥"，获得"我能和马斯克对话"的**身份爽感**。
- 情感核心：**接近一个平时够不着的人**。
- 副产品：和名人在真实英语里对话，本身就是沉浸式语言环境（不是考试）。

### 2.2 非目标用户（v1）
- 以"英语教学 / 应试"为主诉求的用户（英语是副产品，不做教学承诺）。
- 企业客户 / B2B。
- 真实人物本人（人物是 AI 模拟，不是本人）。

### 2.3 关键用户旅程（UJ）
- **UJ-1 和马斯克聊近况**：一个对马斯克好奇的普通用户，打开网页 → 选马斯克 → 按住说话问"你最近在忙啥" → 听到马斯克用自己的语气讲近况 → 聊十分钟不觉得是 AI。
- **UJ-2 问乔布斯怎么看我的决策**：一个纠结创业方向的用户，选乔布斯问"这件事你会怎么做" → 得到"如果乔布斯还活着会怎么看"的判断。
- **UJ-3 沉浸式英语对话**：一个英语学习者，和马斯克用英语聊一个话题 → 在真实语境里练口语，不被纠错打断。

## 3. 术语表
- **人物（Persona / Character）**：一个真实名人的 AI 模拟版，由"思路 + 语气 + 关系"三支柱构成。
- **蒸馏（Distill）**：把一个人的语气、思路、价值观，从其公开资料中提炼成可复用的提示 / 配置。
- **语气（Tone）**：人物的措辞、节奏、口头禅——沉浸感的来源。
- **思路（Thinking）**：人物的价值观棱镜和脑回路——判断"像他"的来源。
- **关系 / 记忆（Memory）**：人物对用户处境与偏好的记忆（MVP 为 Should，非首批）。
- **在世人物 / 历史人物**：仍健在 vs 已故；二者"近期动态"处理方式不同。
- **音色（Timbre）**：语音合成的声线；MVP 用原创 / 授权音色，不克隆真人声线。

## 4. 功能

### 4.1 人物选择与对话
**描述**：用户打开网页，从首批 3 个名人中选择一个，开始 / 结束一段语音对话。实现 UJ-1/UJ-2/UJ-3。`[ASSUMPTION: 无需注册登录，匿名即用]`

**功能需求：**

#### FR-1 选择人物
用户可以从列表中查看并选择一个人物开始对话。实现 UJ-1。
- **测试点**：界面列出至少 3 个名人（马斯克/特朗普/乔布斯）；选择后进入对话态。

#### FR-2 开始 / 结束对话
用户能开始一段对话，并能结束或切换到另一个人物。
- **测试点**：切换人物后，新对话以新人物的语气开场。

### 4.2 语音对话链路
**描述**：核心能力。用户说话 → 语音识别（ASR）→ 人物生成回复（LLM）→ 语音合成（TTS）→ 用户听到。全程流式、低延迟、可打断。实现全部 UJ。`[ASSUMPTION: 入口为网页浏览器麦克风]`

**功能需求：**

#### FR-3 语音输入
用户通过麦克风说话，系统实时识别为文字。
- **测试点**：识别中文 / 英文 / 中英混说，无需输入框也能对话。

#### FR-4 语音输出
人物以语音流式回应，用户无需等整句生成完才开始听。
- **测试点**：首字响应足够快，聊起来不觉得在"等 AI"。

#### FR-5 打断
用户可在人物说话时打断，系统停止当前播放并响应新输入。
- **测试点**：打断后不出现前后两句叠音。

### 4.3 人物"像本人"
**描述**：MVP 的命门与护城河。人物的回应必须用其语气、措辞、思路——像他本人在说话，而不是通用 AI 的复述。实现 UJ-1/UJ-2。使用原创 / 授权音色，不克隆真人声线。

**功能需求：**

#### FR-6 语气一致
人物回应符合其人设的语气、措辞、节奏。
- **测试点**：同一人物多轮对话风格一致；不同人物之间明显可区分。

#### FR-7 思路一致
人物判断体现其价值观棱镜，而非通用模型默认倾向。
- **测试点**：向马斯克与乔布斯问同一个问题，得到各自风格的判断。

#### FR-8 真实与模拟边界
系统明确人物是 AI 模拟（非本人），不冒充真人、不编造私生活；在世人物近期动态仅依据可核实公开资料；历史人物为假设性讨论。
- **测试点**：涉及私生活时系统拒绝编造；首次对话有明确"模拟"说明。

### 4.4 每日播报（Should）
**描述**：MVP 的开口钩子。每天播报名人近况 / 相关新闻，用户对哪条感兴趣就点进去和该名人聊。`[ASSUMPTION: 依赖"跟热点"，MVP 可先以人工 / 静态内容顶上]`

**功能需求：**

#### FR-9 每日播报
系统提供一份当日名人近况列表，点击进入与该名人的对话。
- **测试点**：列表项可点击，并把话题带进对话。

### 4.5 记忆 / 关系（Should）
**描述**：人物记住用户处境与偏好，越来越像"他的"马斯克。`[ASSUMPTION: MVP 后置，非首批交付]`

**功能需求：**

#### FR-10 记忆
人物能延续之前话题、记住用户偏好；用户可查看 / 删除其记忆。
- **测试点**：删除后人物不再引用该记忆。

### 4.6 英语学习（Should）
**描述**：作为对话的副产品。同一个人物可按用户水平调整语言难度、给出口语反馈，但不因此失去其语气与风格。

**功能需求：**

#### FR-11 难度自适应
人物根据用户英语水平调整词汇 / 语速，但不破坏自身风格。
- **测试点**：同一人物对初级与高级用户表达难度不同，风格不变。

#### FR-12 学习反馈
对话结束后给出简要复盘（常见错误、学习词汇）。
- **测试点**：复盘不影响对话流畅性（对话中不频繁打断纠错）。

## 5. 非目标（明确不做）
- 不是英语考试 / 刷题工具；不做独立教学课程。
- 不克隆、不冒充真实人物声线；不以"还原真人声音"为卖点。
- 不做多人 / 多人物同时参与的对话（v1）。
- 不做人物市场、社区上传、开源人物包生态（v1）。
- 不做小爱音箱 / 多设备接入（Could，非 MVP）。
- 不追"名人越来越多"（Won't，先把少数做到爆表）。

## 6. MVP 范围

### 6.1 范围内
- 网页语音对话（ASR→LLM→TTS，流式 + 可打断）。
- 首批 3 个人物：马斯克 / 特朗普 / 乔布斯。
- 人物"像本人"（语气 + 思路 + 原创 / 授权音色）。
- 每日播报（开口钩子，内容可先人工 / 静态）。
- 英语学习作为副产品（难度自适应 + 对话后复盘）。
- 基础记忆 / 关系（可后置，但保留接口）。

### 6.2 范围外（MVP 不做）
- 跟热点 web search（Could，v2）。
- 主动推送话头（Could，v2）。
- 小爱音箱 / 多设备（Could，v3+）。
- 名人越来越多、多语言、开放人物生态（Won't）。

## 7. 成功指标
- **SM-1（主）**：和马斯克聊 10 分钟，不觉得是 AI——"像本人"的验收线。验证 FR-6/FR-7。
- **SM-2（次）**：能发给朋友，朋友玩完问"这怎么做的"——口碑 / 可分享。验证 FR-1/FR-4。
- **SM-3（次）**：乔布斯能聊出"如果他还活着"的味道——历史人物成立。验证 FR-8。
- **SM-C1（反向，勿优化）**：不要为了"回答更像"而去编造真人私生活或冒充本人——真实性边界优先于逼真度。约束 FR-8。

## 8. 待定问题
1. 蒸馏数据源清单：马斯克 / 特朗普 / 乔布斯各自依据哪些公开资料（访谈 / 演讲 / 推特 / 书）？是否需要授权？
2. 语音延迟预算：多少毫秒算"聊起来不像在等 AI"？
3. 是否真的无需注册登录（匿名即用），还是需要轻量身份以保存记忆？
4. 音色来源：原创音色如何制作，还是选接近的通用 / 授权音色？

## 9. 假设索引
- 入口为网页浏览器麦克风（§4.2）。
- 无需注册登录，匿名即用（§4.1）。
- 每日播报依赖"跟热点"，MVP 先以人工 / 静态内容顶上（§4.4）。
- 记忆 / 关系后置，非首批交付（§4.5）。
- 跟热点 / 主动推送 / 多设备为 Could，MVP 不做（§6.2）。

## 10. 约束与红线（安全 / 隐私 / 法律）
- **声音权利**：不克隆真实人物声线；用原创或授权音色。
- **真实 vs 模拟**：人物明确标注为 AI 模拟；在世 / 历史人物区分；真实资料 / 合理推断 / 虚构三者分清；不编造私生活。
- **用户记忆权**：用户可查看 / 修改 / 删除自己的记忆；MVP 无长期记忆前隐私面最小。

## 11. 跨切面非功能需求（NFR）
- **延迟**：语音首字响应与打断需达到"不像在等 AI"的体验（具体预算见 §8 待定问题 2）。
- **沉浸一致性**：同一人物语气 / 措辞在整段会话内稳定。
- **平台**：网页，桌面与手机浏览器均可使用。
