- (decision by coach) chose 4 techniques: Job to Be Done → How Might We → One Feature Only → Ship in 60 Minutes
- (technique by coach) started Job to Be Done
- (idea by user) 与'被蒸馏的人物'对话获取近况与观点：人物用自己的语气讲最近在干什么(含推特发言)、并按自己的思路探讨相关话题，因为AI时代可以蒸馏很多人
- (insight by coach) user 的第一个 JTBD 直觉落在'人物+新闻/近况对话'上，而非练英语——与 README 英语优先的定位存在张力，PRD 需要选一个首要任务
- (idea by user) 人物是真实存在的名人(马斯克/黄仁勋/特朗普/马云/乔布斯等厉害的人)，用户对名人本身很感兴趣
- (insight by coach) 产品更像'与名人/卓越头脑对话'而非英语学习，情感核心可能是'接近够不着的人'；同时触发 README 已强调的真实人物模拟边界与权利问题(约束，收敛阶段处理)
- (idea by user) Job 结晶：让一个我仰慕的头脑(如马斯克)针对我此刻的具体处境/问题，给出他会怎么想的判断——'思考外挂/随身智囊'
- (idea by user) 语气/沉浸很关键：用马斯克自己的语气、措辞、节奏说话，让用户有强烈沉浸感，这是区别于通用AI的关键
- (insight by coach) Job 三大支柱收敛：思路(价值观棱镜/脑回路) + 语气(沉浸感) + 关系(记得用户处境)，缺一根就塌回通用AI
- (technique by coach) ended Job to Be Done; started How Might We
- (idea by user) 日常使用常是低门槛：打个招呼感受'我能和马斯克对话'的爽感/身份感，或随口问'你最近在干什么'——不总是严肃决策
- (insight by coach) 产品真实形态更像'马斯克在你通讯录里'的陪伴/身份体验，而非纯决策工具；'感觉很牛逼'是高频情感回报，可能是MVP日活引擎
- (question by coach) HMW 让用户30秒内就知道此刻该问马斯克什么，把开口门槛降到最低？
- (question by coach) HMW 让语气逼真到像他本人在说话，而不是复读语录或'马斯克可能会说'？
- (question by coach) HMW 让'你最近在忙啥'每次都答得新鲜，像真人在同步近况，而不是重复旧闻？
- (question by coach) HMW 让这个马斯克记住用户的处境和偏好，越来越像'他的'马斯克？
- (question by coach) HMW 让'只是打个招呼'都值得每天回来，成为日活引擎？
- (question by coach) HMW 在'像真人'和'不冒充真人/不编造私生活'之间守住线，既沉浸又不越界？
- (idea by user) 开口门槛解法：模仿每日新闻形式，每天播报名人近况/相关新闻，用户对谁感兴趣就点进去和那个名人聊
- (direction by user) 用户认为语气/新鲜度/关系/爽感/真实边界 这几条已有较好解法，需后续倒出并落到记录里
- (insight by coach) 每日播报把'开口'从用户主动提问变成系统投喂钩子，把最难的主动发起降成被动浏览
- (idea by user) 开口方式2(认可)：根据用户正在纠结的事/正在看的新闻，主动推送某名人'要不要问问他怎么看'
- (insight by coach) 用户说的'已有解法'实为市面/开源已有方案(语气克隆/记忆等)，技术细节他不清楚；因此护城河在人物蒸馏质量+产品体验，不在底层技术
- (technique by coach) ended How Might We; started One Feature Only
- (idea by user) 唯一核心=和名人对话本身；做到极致=有很多名人，尤其当下受关注的名人
- (insight by coach) '多+新+像本人'三者会打架：每个名人都要蒸馏语气/思路/资料，越多越贵、越新越赶，需在MVP阶段排优先级
- (decision by user) 质量优先级排序：像本人 > 跟得上热点 > 名人越来越多；MVP目标是少数名人做到极致像，而非铺量
- (technique by coach) ended One Feature Only; started Ship in 60 Minutes
- (idea by user) MVP 名人选3个：马斯克/特朗普/乔布斯（科技/政治/已故产品家，覆盖不同域，也测试在世与历史两种人物）
- (decision by user) 必须语音，这样才有沉浸感（MVP 语音优先，不是文字聊天框）
- (direction by user) 像本人→参考 GitHub 蒸馏名人的开源项目；跟热点→直接用大模型的 web search
- (decision by coach) 收敛动作选 MoSCoW：把全部候选分进 Must/Should/Could/Won't，产出 PRD 的 MVP 范围
- (decision by user) MoSCoW Must = 1 和名人对话 + 2 语音优先
- (decision by user) MoSCoW Must 补入 4 像本人蒸馏；Should = 3 三名人 + 6 每日播报 + 8 记忆/关系
- (decision by user) MoSCoW Could = 5 跟热点 + 7 主动推送 + 10 小爱音箱/多设备；Won't = 9 英语学习 + 11 名人越来越多 + 12 多语言/开放生态
- (decision by user) 调整：9 英语学习 从 Won't 上移到 Should（第二档）
- (insight by coach) 综合：英语学习是名人对话的副产品(沉浸即学习)，非独立模块；像本人是Must且自动降级记忆/跟热点；Must+Should拼成'播报→沉浸对话→感觉很牛逼'自转飞轮；乔布斯同时测试在世/历史两类人物
