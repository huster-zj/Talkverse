# Talkverse MVP — 意图文档（PRD 输入）

## 1. 一句话定位
与"被蒸馏的名人"对话：名人用自己的语气、思路讲近况、谈观点——像"马斯克在你通讯录里"的沉浸陪伴与身份体验。

## 2. 核心任务 / JTBD
用户"雇佣"Talkverse，是为了让一个自己仰慕的头脑（如马斯克）针对他此刻的具体处境/问题，给出"换作他会怎么想"的判断——思考外挂 / 随身智囊。
日常高频形态更低门槛：打个招呼、随口问一句"你最近在干什么"，获得"我能和马斯克对话"的身份爽感。
情感核心：接近够不着的人。

## 3. 三大支柱（缺一根就塌回通用AI）
1. 思路 — 人物的价值观棱镜 / 脑回路
2. 语气 — 沉浸感（用他自己的语气、措辞、节奏说话）
3. 关系 — 记得用户的处境与偏好

MVP 排位：思路 + 语气（= 像本人）为 Must；关系为 Should（自动降级）；跟热点为 Could。

## 4. 质量优先级
像本人 > 跟得上热点 > 名人越来越多。
MVP 目标是少数名人做到极致像，而非铺量。

## 5. MVP 范围（MoSCoW）
- Must：和名人对话；语音优先；像本人蒸馏
- Should：三位名人（马斯克/特朗普/乔布斯）；每日播报；记忆/关系；英语学习（作为名人对话的副产品）
- Could：跟热点；主动推送；小爱音箱/多设备
- Won't：名人越来越多；多语言/开放生态

## 6. MVP 起步选择
- 人物：3 位——马斯克 / 特朗普 / 乔布斯（科技 / 政治 / 已故产品家，覆盖不同域，同时测试"在世"与"历史"两类人物）
- 语音优先：必须语音，不做文字聊天框，以语音获得沉浸感
- 像本人：参考 GitHub 上蒸馏名人的开源项目
- 新鲜度：跟热点直接用大模型的 web search

## 7. 红线与约束
- 不克隆/冒充真实人物声音；守住"像真人"与"不冒充真人"之间的线
- 区分在世 vs 历史人物（乔布斯即测试"历史人物"边界）
- 真实资料 vs 合理推断 vs 虚构：不编造私生活
- 关系/记忆属于用户：记住的是用户自己的处境与偏好，让这个马斯克越来越像"他的"马斯克
